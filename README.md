## 💻 How to Run Locally

### Option 1: Double-Click
Simply double-click `index.html` to open it in Google Chrome, Microsoft Edge, Firefox, or Safari.

### Option 2: Local HTTP Server (Python)
```bash
# In the portfolio directory:
python -m http.server 5173
```
Then visit `http://localhost:5173` in your browser.

### Option 3: Node / NPX
```bash
npx serve .
```

## 🌐 Deploy to the Web (Free)

1. **GitHub Pages**:
   - Push this folder to a GitHub repository named `portfolio` or `<your-username>.github.io`.
   - Go to **Settings > Pages > Branch: `main` / `root`** and click **Save**.
   - Your portfolio is instantly live!

2. **Vercel or Netlify**:
   - Drag and drop the `Portfolio_Monish` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
